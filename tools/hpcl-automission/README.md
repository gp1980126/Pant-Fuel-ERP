# StationMitra HPCL Automission\n\nLocal discovery/download agent only. It does not connect to Supabase or import into StationMitra. It uses the already logged-in Edge session at 127.0.0.1:9222. Backfill checks 01-Aug-2026 to 18-Nov-2026 in two ranges; daily mode checks today. PDFs, SHA-256 hashes and raw row text are saved under data/. Shared MS/HSD invoice PDFs download once while separate fuel rows are retained. Distinct CNG invoice numbers remain separate.\n\nSetup: run npm install, sign into HPCL manually in Edge started with --remote-debugging-port=9222 and the dedicated profile, then run npm run backfill. Review data/manifest-backfill.json and data/pdf/. After review, install the hourly task with PowerShell: powershell -ExecutionPolicy Bypass -File .\\install-hourly-task.ps1. It schedules hourly checks 8 AM–10 PM. Keep Windows awake and Edge logged in. No passwords or OTPs are stored. Import remains disabled until PDF values are verified against StationMitra preview and HPCL source totals.\n
